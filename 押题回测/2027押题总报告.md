## 第三部分 2027 命题模型（V5）

数据：2005–2026 全部真题（预测 2027 时 2026 真题已入库，属合法信息）。打分公式（每槽位独立排序，槽间做同族互斥）：

```
score = 0.03（基准）
      + 0.9 × 本题型近6年该板块频次（封顶1.35）          ← 题族感知频次
      + 轮空加成：≥15年+1.5 / ≥7年+1.0 / ≥6年+0.8 / ≥5年+0.5 / ≥4年+0.3 / ≥3年+0.15
        （双口径：本题型轮空与全题型轮空取较大档，只增不减）
      + 母机制：板块 8 年内本题型 ≥3 次 → +0.35；3–5 年回归 → +0.21
      × 近考惩罚：考点上年刚考 ×0.25、前年 ×0.75（案例族 ×0.6）
      × 法条槽：部分条文已考 ×0.85；上年同板块 ×0.8、连两年 ×0.5
      + 民法板块换点连考 +0.2 / 刑法 −0.35
      + 对比型：题干有"区别/界限"倾向时 +0.4
      + 新法事件：w=0.9，基础课曲线 age2–3 峰值（0.5/0.7/1.0/0.8/0.5）；简答族 ×0.3
      + "22 年从未进过大题"的考点 +0.4（法条槽）
      + 史料分析：隋唐母朝 +0.3 且不回避连考；其他朝代 d1×0.45/d2×0.7
      + 史简答破零：从未考过简答但史料常客 → +0.9
      + #58 论述：宪法份额 8/9 → 宪法池 +0.5、史池 −0.35
      + #57 论述：法治理论母题 3 年周期回归 +1.0（热点豁免）
      + 案例槽人财板块 ×1.3
```

模型的证据链即第二部分的逐年失分：每条规则都能指认它来自哪一年哪个槽位的教训。防透视约束：预测 2027 只使用 2026 及以前真题与 2026-12-19 前已公布的新法/解释（治安管理处罚法 2026-01-01 施行、监察法修正 2025、婚家解释二 2025、民营经济促进法 2025、新监督法 2025、代表法 2025、侵权解释一 2024、刑十二 2024、国务院组织法 2024）。
