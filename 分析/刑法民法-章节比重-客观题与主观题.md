# 刑法 / 民法 · 章节比重（客观题 vs 主观题）

> 口径：2005–2026 年 22 套真题、1302 道题。每科每年 75 分 → 22 年 **1650 分**；
> 其中**客观题（单选 + 多选）30 分/年 = 660 分**，**主观题（简答 + 法条 + 案例）45 分/年 = 990 分**。
> 表内“占比”分别以 660（客观）和 990（主观）为分母；合计占比以 1650 为分母。
> 排序：按该题型分值**从高到低**。
>

> 刑法客观表已按修正后数据重算（刑法基础与效力由第 2 位降至第 3 位）；主观题不受影响。
> 附录 B 与主报告的**板块级**数字仍按旧标注生成，本次修正对板块占比影响 ≤0.3 个百分点，暂未重算。

## 三、"考过的不会再考"——用数据验一下

你的直觉**部分正确，但需要修正**。我做了两层检验（22 年，制度级考点：刑法 81 个、民法 65 个）：

| 检验口径 | 刑法 | 民法 |
|---|---|---|
| 出现在选择题里的考点（宽松：题干 + 选项） | 81 个 | 65 个 |
| 其中出现在 **≥2 个年份** | 76 个（**94%**） | 58 个（**89%**） |
| 严格口径（只看题干，排除"罪名当干扰项"） | 58 个（**72%**） | 51 个（**78%**） |
| **今年考过 → 明年还考** 的概率（严格口径） | **27%** | **42%** |
| 同一考点两次出现的**中位间隔** | **2 年** | **2 年** |

**结论三句话**：

1. **"考过的不会再考"只在"隔年"这个尺度上成立**：刑法 73%、民法 58% 的考点，第二年不会原样重复。
2. **但拉长到 3 年看，绝大多数考点都会回来**：72%–78% 的考点至少考过 2 次，中位间隔 2 年。
3. 所以准确规律是：**"不连着考，但隔一两年就回来"**。这正好解释了为什么押题要"看近 3 年谁轮空"，而不是"看近 1 年谁考过"。

### 回到你的第二句话：重复考的是不是法条分析？

- **刑法：条文从不重复**。22 道刑法法条分析涉及 22 个不同条文（266、239、234、263、213、26、384、264、24、395、397、29、133、16、30、385、28、111、134、449、17、18），**零重复**。
- **但刑法法条分析"考的板块"在重复**：贪污贿赂 3 次（2011 第384、2014 第395、2020 第385）、犯罪主体 3 次（2019 第30、2025 第17、2026 第18）、量刑 2 次（2021 第28、2024 第449）、危害公共安全 2 次（2017 第133、2023 第134）、共同犯罪 2 次（2010 第26、2016 第29）。
- **民法确实出现过条文重复**：《民法通则》第 93 条（无因管理）在 **2006、2017** 各考一次；制度层面"准合同（无因管理 + 不当得利）"共 3 次（2006、2008、2017），是民法法条分析里重复率最高的板块。
- 结论：**法条分析不重复"条文"，但重复"板块"**。所以押题应该押"板块 + 可命制的条文"，而不是押具体条号。

## 六、一句话总结

- **选择题的规律不是"考过不考"，而是"隔 2 年回来"**：今年考过的，明年 70% 不重复；三年内 72%–78% 都会回来。
- **法条分析不重复条文、只重复板块**（刑法 22 年零重条；民法仅《民法通则》93 条重过一次）。
- **刑法选择题的重心是总则，刑法大题的重心是分则**；**民法选择题的重心是总则+合同通则，民法大题的重心是典型合同+担保物权**——这四条线决定了你的时间怎么分。
